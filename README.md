## 📖 项目简介

本项目为专为光遇陪伴/三恋风格打造的个人资料与服务展示网站，特色包括：
1. **欢迎界面（Welcome）**：黑白冷淡风/百合花与双鸦主题视觉，快速进入档案。
2. **个人简介（Intro）**：昵称、人设标签、出没时间、语音偏好及自我介绍。
3. **风格展示（Style）**：光遇穿搭风格卡片、外观图集与人设关键词。
4. **四大核心分类（Categories）**：
   - 📋 **须知（Rules）**：接单规则、相处禁忌与预定说明。
   - 💬 **板评（Board Reviews）**：客户留评、口碑反馈墙。
   - 🎙️ **话术（Sample Dialogues）**：日常相处、安慰、道早晚安等互动片段。
   - 🌟 **陪评（Companion Reviews）**：陪伴案例与详细记录。
5. **本地编辑与持久化**：支持在线直接编辑内容并持久化保存。

- **样式**：Tailwind CSS + Lucide React 图标库
